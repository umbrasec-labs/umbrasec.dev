OPEN SOURCE / SIGMA-PACK

sigma-pack.

The detection rules and queries from the UMBRASEC research writeups, as runnable files. Every rule comes out of a writeup that explains the technique, the log artifacts, the tuning knobs, and the false-positive profile. Read that before you deploy the rule.

Each file below is served directly over HTTPS - no account, no clone. Validate anything here yourself before running it; sigma-cli will syntax-check the whole directory.

experimental is the Sigma status the rules themselves declare - new rules, not yet battle-tested across many environments. KQL queries carry no Sigma status.

FETCH ONE RULE

curl -sO https://umbrasec.dev/tools/sigma-pack/rules/windows/kerberoasting-spn-fanout.yml

Every path in the table works the same way. Rules are plain YAML, queries are plain text.

TAKE THE WHOLE PACK

git clone https://codeberg.org/0xdev1/umbrasec

The pack lives in tools/sigma-pack/, alongside the writeups each rule came from.
