OPEN SOURCE

Open source.

Small defensive artefacts from the writeups - rules and the ledger that tests them, a KEV monitor, Claude Code skills for blue teams, and two visual references. They are evidence of how the work is done, not a product line. Status labels are honest.

kev-watch
WORKING

A zero-dependency Python monitor for the CISA Known Exploited Vulnerabilities (KEV) catalog. Tracks newly added, actively-exploited CVEs and flags ones that match products you care about. Public data only.

Read the source → View on GitHub →

curl -sO https://umbrasec.dev/tools/kev-watch/kev_watch.py

sigma-pack
EARLY

The Sigma rules and KQL queries from the research writeups, shipped as runnable files - Sigma rules for Kerberoasting, the LiteLLM command injection, N-central post-exploitation, the Metabase reset-password SQL injection and php2shell upload-progress probes, and ransomware recovery inhibition, Defender tampering, admin-share archiving, rclone transfers and remote access tools installed as a service from the SafePay and INC Ransom writeups, plus four KQL queries for OAuth consent phishing and the app-credential persistence that can follow it, each mapped to its ATT&CK technique. Grows one writeup at a time.

Browse the pack → View on GitHub →

curl -sO https://umbrasec.dev/tools/sigma-pack/rules/windows/kerberoasting-spn-fanout.yml

Claims Ledger
detections EARLY

The Claims Ledger for sigma-pack. Each rule's claims about itself - what it catches, which harmless activity trips it, what it cannot see - are written down and re-proved in CI against the live rule files, using labelled synthetic events. Every run, pass or fail, is signed for the exact rule digests.

umbra-blue
WORKING

77 defensive skills for Claude Code: drop-in SKILL.md files for detection engineering, incident response, threat hunting and hardening, mapped to ATT&CK and D3FEND. The ten Tier 1 skills ship the tuned sigma-pack rule itself, with tuning and false-positive notes. No exploit code or offensive tooling.

Blue Team Mapper
LIVE

An interactive map of blue team operations: a radial lifecycle map, architecture layers with P0/P1/P2 key controls, flow graphs for eight incident-response chains with decision branches and approval gates, a filterable ATT&CK technique matrix, and search across all of it. Built for analysts who need actionable depth.

Open the mapper → View on GitHub →
Red Team Mapper
LIVE

The Blue Team Mapper's counterpart: a visual reference of how attacker operations are structured - a radial operation lifecycle, reference sections and end-to-end flow chains - mapped so defenders know what to hunt for and where coverage is thin. A reference, not tooling: it describes techniques and names public tools, and ships nothing to run.
